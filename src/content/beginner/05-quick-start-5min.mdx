## 从零到生产力：5 步搞定

本节是一个浓缩的实战指南，带你在 5 分钟内从安装到实际使用 Claude Code。如果你已经完成了前面几节的学习，这里将帮你串联所有知识点；如果你是直接跳到这里的急性子，跟着做就对了。

## 第 1 步：安装（1 分钟）

确保你已安装 Node.js 18+，然后执行：

```bash
npm install -g @anthropic-ai/claude-code
```

验证安装：

```bash
claude --version
```

<CalloutBox type="warning">
如果 `node --version` 显示低于 18 的版本或提示未安装，请先参考「安装 Claude Code」章节配置 Node.js 环境。
</CalloutBox>

## 第 2 步：登录认证（30 秒）

### 方式 A：OAuth 登录（推荐）

```bash
claude login
```

浏览器会自动打开，完成登录授权即可。

### 方式 B：API Key

```bash
export ANTHROPIC_API_KEY="sk-ant-your-key-here"
```

## 第 3 步：进入项目目录（10 秒）

切换到你想让 Claude 帮忙的项目：

```bash
cd ~/my-project
```

<CalloutBox type="tip">
选择一个你熟悉的真实项目来练习效果最好。如果手边没有项目，可以 clone 一个开源项目来试试，例如：`git clone https://github.com/vuejs/petite-vue.git && cd petite-vue`
</CalloutBox>

## 第 4 步：启动 Claude Code（10 秒）

```bash
claude
```

看到欢迎界面后，你就可以开始对话了。

## 第 5 步：尝试基础任务（3 分钟）

现在，试试以下三个典型任务，感受 Claude Code 的能力。

### 任务 1：理解项目

输入以下内容：

```
帮我梳理一下这个项目的整体架构和目录结构
```

**预期结果**：Claude 会扫描项目文件，然后输出一份清晰的项目概述，包括：
- 项目用途和技术栈
- 核心目录结构说明
- 主要入口文件和关键模块

这是你接手新项目或回顾老项目时最常用的操作之一。

### 任务 2：查找和解释代码

选择项目中的一个文件，让 Claude 帮你解释：

```
解释 src/index.ts 中的主要逻辑，特别是导出了哪些功能
```

**预期结果**：Claude 会读取指定文件，然后逐段解释代码逻辑，包括：
- 文件的整体职责
- 关键函数和类的作用
- 导入导出关系
- 可能存在的注意事项

<CalloutBox type="info">
将上面的文件路径替换为你项目中实际存在的文件。Claude 会自动读取对应文件并进行分析。
</CalloutBox>

### 任务 3：修改代码

让 Claude 为你的项目做一个小改动：

```
在 README.md 的开头添加一个项目徽章，显示 Node.js 版本要求 >= 18
```

**预期结果**：
1. Claude 会读取现有的 `README.md`
2. 生成修改方案并显示 diff
3. 请求你确认是否应用修改
4. 你输入 `y` 后，修改会被写入文件

这个过程展示了 Claude Code 的核心工作流：理解需求 -> 生成方案 -> 请求确认 -> 执行修改。

## 三个好用的入门提示词

掌握了基本流程后，这里再给你三个日常开发中非常实用的提示词模板：

### 代码审查

```
审查 src/utils/ 目录下的所有文件，指出潜在的 bug、
性能问题和不符合最佳实践的地方
```

Claude 会逐个文件审查，并给出具体的改进建议和修改代码。

### 编写测试

```
为 src/services/userService.ts 中的所有公开函数编写单元测试，
使用 Jest 框架，覆盖正常和异常场景
```

Claude 会分析源代码，然后生成完整的测试文件，包括 mock 数据和边界情况的处理。

### 重构代码

```
将 src/components/Dashboard.tsx 拆分成更小的子组件，
每个组件职责单一，保持功能不变
```

Claude 会分析当前组件，提出拆分方案，创建新的子组件文件，并更新原组件的引用。

## 快速参考卡片

以下是你需要记住的核心操作：

| 操作 | 命令 |
|------|------|
| 安装 | `npm install -g @anthropic-ai/claude-code` |
| 登录 | `claude login` |
| 启动 | `claude` |
| 快速提问 | `claude -p "你的问题"` |
| 继续上次会话 | `claude -c` |
| 查看帮助 | 会话中输入 `/help` |
| 压缩上下文 | 会话中输入 `/compact` |
| 查看费用 | 会话中输入 `/cost` |
| 退出 | 会话中输入 `/exit` |

恭喜你完成了 Claude Code 的入门学习！你现在已经掌握了：

- 安装和配置 Claude Code
- 启动交互式会话并进行对话
- 使用各种命令和参数
- 选择适合自己的订阅方案
- 实际动手完成常见的开发任务

要进一步提升你的 Claude Code 使用技巧，建议按以下顺序继续学习：

- **中级教程 - CLAUDE.md 入门**：学习如何通过配置文件让 Claude 更好地理解你的项目
- **中级教程 - 提示词技巧**：掌握更高效的对话方式，用更少的 token 完成更多任务
- **实战教程**：跟随完整的项目案例，体验 Claude Code 在真实开发场景中的应用

<CalloutBox type="tip">
学习的最好方式就是在真实项目中实践。从今天开始，把 Claude Code 融入你的日常开发工作流中，你会发现它的能力远超你的想象。
</CalloutBox>
