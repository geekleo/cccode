## 方案概览

Claude Code 提供多种使用方式，从按量付费到固定订阅，覆盖个人开发者到企业团队的不同需求。了解各方案的特点有助于你做出最经济高效的选择。

## API 按量付费

这是最灵活的使用方式，适合想要精确控制成本的开发者。

### 使用方式

- 在 [Anthropic Console](https://console.anthropic.com/) 注册账户并获取 API Key
- 通过环境变量设置 API Key 后即可使用
- 按实际消耗的 token 数量计费

### 计费方式

API 计费基于输入和输出的 token 数量，不同模型的费率不同：

| 模型 | 输入价格（每百万 token） | 输出价格（每百万 token） |
|------|--------------------------|--------------------------|
| Claude Sonnet 4 | $3 | $15 |
| Claude Opus 4 | $15 | $75 |

### 适合人群

- 使用频率不固定的开发者
- 想要先试用再决定是否订阅的用户
- 需要在 CI/CD 等自动化场景中使用的团队

<CalloutBox type="tip">
API 按量付费模式下没有固定月费，你只需为实际使用量付费。对于偶尔使用的开发者来说，这通常是最经济的选择。可以在 Anthropic Console 中设置用量预算上限，避免意外超支。
</CalloutBox>

## Claude Pro 方案

Claude Pro 是面向个人用户的订阅方案，包含在 Anthropic 的 Pro 订阅中。

### 价格

每月 **$20**

### 主要特点

- 包含 Claude Code 的使用额度
- 每日有一定的使用量上限
- 可同时在 claude.ai 网页端和 Claude Code CLI 中使用
- 通过 `claude login` 进行 OAuth 认证即可使用

### 适合人群

- 日常使用 Claude 进行编程辅助的个人开发者
- 同时需要网页版和命令行版的用户
- 使用频率中等，每日使用量在限额内的用户

## Claude Max 方案

Claude Max 是为高频用户设计的高级订阅方案，提供更高的使用限额。

### 价格

每月 **$100** 或 **$200**（不同档位）

### 主要特点

- **显著更高的使用量上限**：比 Pro 方案高出 5 倍到 20 倍
- 优先访问最新模型
- 更快的响应速度
- 适合全天候高强度使用

### 适合人群

- 全职依赖 Claude Code 进行开发的工程师
- 每天需要大量代码生成、审查和重构的用户
- 对响应速度有较高要求的专业开发者

<CalloutBox type="info">
如果你发现自己在使用 Pro 方案时经常遇到速率限制，升级到 Max 方案会是一个明智的选择。Max 方案的更高限额可以确保你的工作流不被打断。
</CalloutBox>

## Claude Team 方案

面向小型到中型团队的协作方案。

### 价格

每人每月 **$30**（按年付费）或 **$35**（按月付费）

### 主要特点

- 团队成员共享管理控制台
- 比 Pro 方案更高的使用量上限
- 团队数据不会用于模型训练
- 管理员可以管理成员和查看使用情况
- 支持 SSO（单点登录）等企业功能

### 适合人群

- 3 人以上的开发团队
- 需要统一管理和计费的小型公司
- 对数据隐私有要求的团队

## Claude Enterprise 方案

面向大型企业的定制方案，提供最全面的功能和最高级别的安全保障。

### 主要特点

- **自定义使用量上限**：根据企业需求灵活配置
- **高级安全功能**：SAML SSO、SCIM、审计日志
- **专属支持**：优先客户支持和技术顾问
- **合规保障**：满足 SOC 2 等合规要求
- **数据隔离**：企业数据完全隔离，绝不用于训练
- 支持自定义部署方案

### 适合人群

- 大型开发团队（50 人以上）
- 对安全合规有严格要求的企业
- 需要定制化方案的组织

<CalloutBox type="info">
Enterprise 方案需要联系 Anthropic 销售团队获取定制报价。可以通过 Anthropic 官网的联系方式提交需求。
</CalloutBox>

## 如何选择适合你的方案

### 决策流程

根据以下问题逐步判断：

**第一步：评估使用频率**

- 偶尔使用（每周几次）：API 按量付费
- 每天使用：Pro 或更高方案
- 全天高强度使用：Max 方案

**第二步：评估使用场景**

- 个人项目 + 轻度使用：Pro 方案
- 个人项目 + 重度使用：Max 方案
- 团队协作：Team 方案
- 企业级需求：Enterprise 方案

**第三步：评估预算**

- 预算有限，想按需付费：API 按量付费
- 愿意月付固定费用换取便利：Pro / Max
- 团队统一管理预算：Team / Enterprise

### 方案对比总结

| 特性 | API 按量 | Pro | Max | Team | Enterprise |
|------|----------|-----|-----|------|------------|
| 月费 | 按量 | $20 | $100/$200 | $30/人 | 定制 |
| 使用量限制 | 仅预算 | 中等 | 高 | 较高 | 自定义 |
| 认证方式 | API Key | OAuth | OAuth | OAuth + SSO | SAML SSO |
| 数据训练 | 否 | 否 | 否 | 否 | 否 |
| 团队管理 | 无 | 无 | 无 | 有 | 高级 |

## 节省 token 的技巧

无论你使用哪种方案，以下技巧都能帮你更高效地使用 Claude Code：

### 精准描述需求

```
# 不够具体，可能需要多轮对话
帮我改改这个文件

# 具体明确，一轮就能完成
在 src/api/users.ts 的 getUser 函数中添加错误处理，
当用户不存在时返回 404 状态码和错误消息
```

### 善用 /compact 命令

对话变长时，及时使用 `/compact` 压缩上下文，减少每次请求的 token 消耗。

### 合理使用 /clear

当切换到不相关的新任务时，使用 `/clear` 清除旧对话，避免无用上下文占用 token。

### 使用非交互模式处理简单任务

对于简单查询，使用 `claude -p` 非交互模式比启动完整会话更高效：

```bash
# 快速查询，不需要完整会话
claude -p "package.json 中 react 的版本是多少"
```

### 充分利用 CLAUDE.md

在 `CLAUDE.md` 中提前写好项目上下文（技术栈、代码规范、常用命令等），可以减少每次对话中解释背景的 token 消耗。

<CalloutBox type="tip">
建议新用户从 API 按量付费或 Pro 方案开始使用。在了解自己的使用模式后，再根据实际情况升级到更高级的方案。这样可以避免一开始就为不需要的容量付费。
</CalloutBox>
